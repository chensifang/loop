iOS 程序启动流程

整体流程

阶段 步骤
1. 系统启动阶段 系统启动 → 内核加载 App 可执行文件 → 创建进程
2. 动态链接阶段 dyld 动态链接器启动 → 加载动态库 → Rebase & Bind
3. 初始化阶段 调用 +load 方法 → 调用 C++ 静态构造函数
4. main 函数阶段 调用 main 函数 → UIApplicationMain
5. 应用启动阶段 创建 UIApplication 实例 → 创建 AppDelegate 实例 → 设置 UIApplication 的 delegate → 启动主 RunLoop → 调用 didFinishLaunching
6. 界面显示阶段 创建 Window → 设置 RootViewController → 视图控制器加载 → 视图布局 Layout → 视图绘制 Display → 提交到 Render Server → GPU 渲染 → 显示到屏幕
